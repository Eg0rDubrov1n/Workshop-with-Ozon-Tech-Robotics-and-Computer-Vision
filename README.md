# dimensioning.py — определение габаритов 3D-объекта по STL

Минимальный демонстрационный пайплайн для автоматического определения
**длины, ширины и высоты** произвольного объекта по его STL-модели.
Реализует классическую связку алгоритмов вычислительной геометрии:

1. **Выпуклая оболочка** проекции объекта на плоскость XY.
2. **Минимальный по площади охватывающий прямоугольник** через
   *rotating calipers* (теорема Фримана–Шапиры).
3. **Независимый замер высоты** по оси Z.
4. **3D-визуализация**: объект + охватывающий параллелепипед + подписи
   габаритов прямо в сцене.

---

## Статус проекта

Код является **тестовым / демонстрационным**. Он написан для того, чтобы
показать работу алгоритма на реальной STL-модели, а не для
промышленной эксплуатации. В частности:

- нет юнит-тестов, CI и строгой обработки всех вырожденных случаев;
- визуализация зависит от наличия Open3D или matplotlib в системе;
- при написании кода использовался ассистент **DeepSeek** — большая
  часть текста, комментариев и структуры сгенерирована им, а затем
  проверена и доработана вручную.

## Как это работает

### Этап 1. Выпуклая оболочка

Используется `scipy.spatial.ConvexHull` — обёртка над
[Qhull](http://www.qhull.org/). Точки модели проецируются на плоскость XY
и по ним строится выпуклый многоугольник, содержащий все точки.

### Этап 2. Минимальный охватывающий прямоугольник (Rotating Calipers)

Минимальный по площади прямоугольник, содержащий выпуклый многоугольник,
всегда имеет сторону, **коллинеарную одному из рёбер оболочки** —
это теорема Freeman & Shapira (1975). Значит, достаточно перебрать `O(h)`
углов (по числу рёбер оболочки), а не сканировать все углы от 0° до 90°.
Метод вращающихся калиперов (Toussaint, 1983) даёт линейное время `O(h)`
на один проход по оболочке.

### Этап 3. Высота

Высота — независимая величина, берётся как `max(Z) − min(Z)` по облаку
точек. Это сознательное упрощение: для объектов с наклоном относительно
осей координат «честная» высота относительно минимального параллелепипеда

## Первоисточники

Алгоритмы и теоремы, на которые опирается код:

1. **T. M. Chan.** *Optimal Output-Sensitive Convex Hull Algorithms in
   Two and Three Dimensions.* Discrete & Computational Geometry,
   vol. 16, pp. 361–368, 1996.
   Оригинальный выход-чувствительный алгоритм построения выпуклой оболочки
   за `O(n log h)`, где `h` — число вершин оболочки. Идея группировки
   точек и «угадывания» `h` через удвоение размера группы.

2. **H. Freeman, R. Shapira.** *Determining the Minimum-Area Encasing
   Rectangle for an Arbitrary Closed Curve.* Communications of the ACM,
   vol. 18, no. 7, pp. 409–413, July 1975.
   Доказательство теоремы о том, что сторона минимального прямоугольника
   коллинеарна ребру выпуклой оболочки, и схема алгоритма `O(n²)`.

3. **G. T. Toussaint.** *Solving Geometric Problems with the Rotating
   Calipers.* Proceedings of IEEE MELECON'83, Athens, 1983.
   Обобщение идеи вращающихся калиперов Шеймоса на несколько пар
   одновременно и получение оптимального `O(n)` алгоритма для
   минимального охватывающего прямоугольника и ряда других задач.

## Установка и запуск
Требования:
- Python 3.9+
- `numpy`, `scipy` — обязательно
- `open3d` — опционально 
- `matplotlib` — опционально

```bash
### 2. Установка
pip install numpy scipy

pip install open3d matplotlib

```

## Команды запуска

Все примеры ниже предполагают, что в текущем каталоге лежит `model.stl`.

### Базовый запуск (с визуализацией)

bash

python dimensioning.py model.stl

### Только числа, без окна (полезно для скриптов и CI)

bash

python dimensioning.py model.stl --no-viz

### Ограничить число точек (если модель тяжёлая)

По умолчанию после загрузки облако прореживается до 100 000 точек.  
Для очень плотных сеток имеет смысл уменьшить лимит — конвейер заметно  
ускорится, а габариты изменятся в пределах долей процента:

bash

python dimensioning.py model.stl --max-points=50000
python dimensioning.py model.stl --max-points=20000

### Комбинация флагов

bash

python dimensioning.py model.stl --max-points=30000 --no-viz
